# ✈️ Air Traffic Analysis Dashboard (Big Data Project)

## 🚀 Key Insights
- Passenger traffic increased significantly over time
- Freight trends show seasonal fluctuations
- Airline distribution highlights dominant carriers

## 📌 Overview

This project focuses on analysing large-scale aviation datasets to understand passenger and freight traffic trends. The goal was to design interactive dashboards for business insights using Power BI.

## 🎯 Objectives

* Analyse passenger and freight traffic trends
* Understand airline performance and traffic flow
* Build interactive dashboards for decision-making

## 🧠 Technologies Used

* Power BI
* DAX (Data Analysis Expressions)
* Data Modelling (Star Schema)
* Data Cleaning & Transformation

## 📊 Dataset

* Large-scale aviation datasets (100M+ records)
* Includes:

  * Passenger traffic
  * Freight traffic
  * Airline information
  * Time-based data (Year, Month)

## ⚙️ Process

1. Data cleaning and transformation
2. Data modelling using star schema
3. Creation of relationships between tables
4. Development of DAX measures
5. Dashboard design and visualisation

## 📈 Key Features

* Interactive filters (Year, Month, Airline, Carrier Type)
* KPI cards for total passenger and freight traffic
* Trend analysis over time
* Airline-level performance insights
* Geographic visualisation (map-based analysis)

## 📊 Dashboard Components

* Passenger Traffic Analysis
* Freight Traffic Analysis
* Year-over-Year comparison
* Airline distribution
* Route-based insights

## 🚀 Results

* Built scalable dashboards for large datasets
* Enabled quick filtering and drill-down analysis
* Delivered clear insights for airline traffic patterns


## 🔗 Future Improvements

* Integrate real-time aviation data
* Add predictive forecasting
* Deploy dashboard to cloud platform
